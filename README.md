# Incidex
Incidex is a dynamic web application designed to report, manage, and track cybersecurity incidents through a centralized dashboard.

## Database

PostgreSQL schema, data-access layer, demo data, and setup steps are in [`database/README.md`](database/README.md).
Quick start: copy `.env.example` to `.env`, add your `DATABASE_URL`, then run `npm install`, `npm run db:setup`, and `npm run db:test`.
